# Recomendador de Filmes

Programa em **p5.js** que recomenda um filme de acordo com a idade e as preferências do usuário (fantasia e aventura).

## Como funciona

Digite a idade e marque se gosta de fantasia e/ou aventura. A função `geraRecomendacao()` escolhe entre títulos como *A viagem de Chihiro*, *As aventuras de Pi*, *Homem-Aranha: no Aranhaverso* e *O menino que descobriu o vento*.

## Tecnologias

JavaScript com [p5.js](https://p5js.org/) 1.10 (`createInput`, `createCheckbox`).

## Como usar

Abra o `index.html` no navegador, ou use o Live Server do VS Code.

## Branches

A versão mais nova está no branch `NovoRecomendaFilme`.
